# Contributing Guidelines | راهنمای مشارکت

Thank you for your interest in contributing to our projects! We welcome contributions, discussions, and improvements.

## Code of Conduct
Please be respectful and constructive in all interactions.

## How to Contribute
1. Fork the repository
2. Create your feature branch (`git checkout -b feature/amazing-feature`)
3. Follow [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `docs:`)
4. Commit your changes
5. Push to the branch (`git push origin feature/amazing-feature`)
6. Open a Pull Request
